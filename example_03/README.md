# Logging
Debugging, trace your code

## Run the following commands

### Initialize npm
```
npm init -y
```

### Install express
```
npm install express
npm install --save-dev nodemon
```

### Open in VS Code
```
code .
```

### Run server
```
npm run devStart
```

### Open browser

Go to

```
http://localhost:3000/
```

### Shutdown server

```
CTRL + C
```
