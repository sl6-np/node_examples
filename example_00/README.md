# Simple backend server - part 1
Run an Express server

## Run the following commands

### Initialize npm
```
npm init -y
```

### Install express
```
npm install express
```

### Open in VS Code
```
code .
```

### Run server
```
node server.js
```

### Open browser

Go to

```
http://localhost:3000/
```

### Shutdown server

```
CTRL + C
```
