# Simple backend server - part 2
Edit, restart, refresh

## Run the following commands

### Initialize npm
```
npm init -y
```

### Install express
```
npm install express
```

### Open in VS Code
```
code .
```

### Run server
```
node server.js
```

### Open browser

Go to

```
http://localhost:3000/
```

### Shutdown server

```
CTRL + C
```

# Exercise
Make a small change in get request to send a different response. Refresh your browser. Did the response change? Why?

Shut down the server and start it again. Refresh your browser. Did the response change?

Make another change in the get request to send another response. What do you see now?
